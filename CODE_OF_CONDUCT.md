# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions focused on the work. Harassment of any kind is not tolerated.

Report unacceptable behavior privately through the maintainer's contact on the GitHub profile, or by opening a [private security advisory](../../security/advisories/new) if the matter is sensitive. Reports are handled confidentially.
